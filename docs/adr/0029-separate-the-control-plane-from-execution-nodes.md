# Separate the control plane from execution nodes

The product will combine a full Windows and macOS FDE workbench, a lightweight browser portal for enterprise participation and administration, a deployable control plane for shared engagement state and audit history, and authorized desktop or server execution nodes for models, agents, browsers, builds, and tests. This separation lets collaboration remain consistent while execution stays near the code, tools, and credentials it requires instead of turning the control plane into a universal custody environment.
