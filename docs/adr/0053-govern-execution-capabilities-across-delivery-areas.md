# Govern execution capabilities across delivery areas

Skills, MCP servers, models, agents, adapters, and tools will be governed as reusable execution capabilities rather than embedded independently into delivery-area implementations. The workbench will distinguish availability, selection, and actual use; disclose version, health, permission, data destination, execution location, cost expectation, and outputs as applicable; and retain an attributable capability-use record for generated outcomes. Selection precedence is organization hard policy, engagement data and budget policy, delivery-area configuration, FDE selection, and finally Decision API recommendation; an unavailable capability cannot be silently substituted unless a policy-compliant fallback rule was declared in advance.
