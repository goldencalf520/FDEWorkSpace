# Accept integrations through a verified matrix

Initial-release integration claims require tested adapters for recording upload and Feishu meetings; local Git, GitHub, and Gitee; Playwright browser testing; OpenAI-compatible, Anthropic-compatible, and Ollama or vLLM local model access; Codex and Claude Code coding-agent paths; local CI and GitHub Actions; and Figma authorized file access. An extension seam may exist for GitLab and additional platforms, but an adapter is not supported until its declared capabilities, permissions, failure modes, compatibility, and recovery have been verified.
