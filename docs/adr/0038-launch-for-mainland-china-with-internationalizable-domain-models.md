# Launch for mainland China with internationalizable domain models

The initial market will prioritize mainland-China FDE delivery: Chinese and mixed Chinese-English use, Feishu, domestic model and API options, domestic network conditions, and applicable data requirements receive first-class validation. The interface and templates begin in Chinese, but core identities, text, numbers, time, layout, and domain objects remain internationalizable so later markets extend one product rather than forking a separate English implementation.
