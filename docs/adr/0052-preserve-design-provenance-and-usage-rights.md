# Preserve design provenance and usage rights

External sites, applications, screenshots, recordings, Figma files, marketplace assets, and private templates will enter the workbench as classified, attributable sources with separate access authority and usage rights. The workbench will preserve a derivation chain from reference capture through design interpretation to newly generated prototype and source code, will not relabel reference material as owned templates, and will neither bypass access controls nor imply that technical access grants commercial reuse rights.
