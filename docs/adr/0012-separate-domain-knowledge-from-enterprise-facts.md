# Separate domain knowledge from enterprise facts

The workbench will maintain a continuously extensible domain library whose uploaded or connected sources retain provenance, version, knowledge scope, access rights, and usage-license information while moving through explicit upload, parse, index, review, and publication states. Retrieval authorization must filter indexed fragments before model access, and every fragment must remain traceable to its original source and version. Withdrawn material is excluded from new retrieval while historical engagements retain an audit reference to the version they used; conflicting sources remain separately attributable for an FDE applicability decision. Retrieval produces explainable match candidates and reusable domain patterns for individual findings and process elements, but it must not silently overwrite enterprise evidence or present a general industry pattern as a fact about the current enterprise.
