# FDE Workbench draft prototypes

These files preserve the current product-design checkpoint. They are discussion artifacts, not production UI or an approved implementation baseline.

- `fde-workbench-entry-first.html`: interactive draft with the system blueprint and three workbench layout variants.
- `fde-workbench-blueprint.png`: static preview of the system blueprint.
- `fde-workbench-panel-a.png`: recommended entry-card layout with Takeover and Requirements at equal primary prominence.
- `fde-workbench-panel-b.png`: persistent entry-rail layout.
- `fde-workbench-panel-c.png`: import-command-center layout.

The prototype remains subject to revision. Product behavior is governed by the formal design, glossary, and ADRs in this repository.
